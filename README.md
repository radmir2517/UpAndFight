# UpAndFight

Небольшая игра в жанре РПГ, где мы играем за волшебницу, которой предстоит воевать против разных существ аля милых гоблинов и троллей. Есть AbilitySystemCOmponent и мультиплеер, реализуется в данный момент прокачка персонажа через меню с выбором, что хочет игрок. Открытие новых заклинаний с уровнями игрока.
